# ComfyUI-DJ_Batch

> 版本 `261010-024730` · 作者：大江

批次工具箱：两个「逐个加载」节点，一个管音频、一个管图片。每次执行只加载一个文件，进度自动记录，到末尾从头循环。

## ✨ 功能总览

| 节点 | 输入 | 输出 | 支持格式 |
|---|---|---|---|
| **批量批次音频** `ComfyUI-DJ_批量批次音频` | 文件夹 / .zip | AUDIO + 文件名 | wav / mp3 / aac |
| **批量批次图片** `ComfyUI-DJ_批量批次图片` | 文件夹 | IMAGE + 文件名 | jpg / jpeg / png / webp / gif / bmp / tiff / avif |

两个节点共用同一套机制：
- 每次执行只加载一个文件，进度用 SQLite 记录，不同标签（批次）独立计数
- 到末尾自动回到开头循环
- 自然排序：file2 < file10，支持阿拉伯数字、中文小写/大写数字（一/壹）、中英文括号归一化
- 路径或排序方式变了，进度自动归零

## 安装

把 `ComfyUI-DJ_Batch` 文件夹放进 ComfyUI 的 `custom_nodes\`，重启 ComfyUI。

## 节点 1：批量批次音频

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| 路径 | STRING | — | 文件夹路径或 .zip 文件路径 |
| 标签 | STRING | Batch 001 | 批次标签，不同标签独立计数 |
| 排序方式 | 下拉 | 文件名正序 | 自然排序 / 文件名正序 / 文件名倒序 |
| 最大文件数 | INT | 0 | 0 = 不限制；>0 时只取前 N 个 |
| 重置进度 | 下拉 | 否 | 选「是」清空当前标签的进度 |

**输出**：`音频` AUDIO tensor `[1, C, S]` float32 + `文件名` STRING。

## 节点 2：批量批次图片

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| 路径 | STRING | — | 图片文件夹路径 |
| 标签 | STRING | Batch 001 | 批次标签，不同标签独立计数 |
| 文件过滤 | STRING | * | 通配符，如 `*.png`、`图*.jpg`；`*` = 全部 |
| 排序方式 | 下拉 | 文件名正序 | 正序 / 倒序 / 随机（同一种子可复现） |
| 随机种子 | INT | 0 | 仅随机模式生效 |
| 输出格式 | 下拉 | RGB | RGB / RGBA |
| 文件名带扩展名 | 下拉 | 是 | 输出文件名是否含 .png 等后缀 |
| 最大文件数 | INT | 0 | 0 = 不限制；>0 时只取前 N 张 |
| 重置进度 | 下拉 | 否 | 选「是」清空当前标签的进度 |

**输出**：`图片` IMAGE tensor `[1, H, W, C]` float32（0~1）+ `文件名` STRING。EXIF 方向自动纠正。
